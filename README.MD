# 🛡 Firewall Rule Analyzer Pro

Professional Firewall Security Assessment Tool built using Python and Streamlit.

## Features

- Firewall Rule Analysis
- Risk Scoring Engine
- Security Recommendations
- Security Dashboard
- PDF Audit Reports
- Firewall Health Score
- Severity Classification

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- ReportLab
